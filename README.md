# Sensing Leeds Air Quality

MSc Dissertation Project

## Project Overview

This project investigates PM2.5 air quality measurements from the Leeds sensor network.

The objectives are:

1. Build a standard view of air quality behaviour across Leeds.
2. Compute Concentration Similarity Index (CSI) matrices.
3. Cluster sensors according to similarity patterns.
4. Detect unusual pollution events.
5. Distinguish real pollution events from sensor faults.
6. Develop a near-real-time monitoring tool.

## Dataset

- Leeds PM2.5 sensor network
- Simulated datasets provided by supervisors
- AURN reference station data (if available)

## Methods

- Concentration Similarity Index (CSI)
- Hierarchical Clustering
- Fuzzy C-Means Clustering
- Outlier Detection
- Missing Data Handling
- Event vs Fault Classification
